# Task provenance

The task is a compact KiCad 10 adaptation of the MIT-licensed `pilinux/nRF24breakoutBoard`, which also appears in the MIT-licensed PCBench real-board routing corpus.

- Original project: https://github.com/pilinux/nRF24breakoutBoard
- Dataset record: https://github.com/PCBench/PCBench/tree/main/PCBs/nRF24breakoutBoard_nRF24-breakout
- Adaptation: the same practical module/header/decoupling topology is redrawn with stock KiCad footprints and selected routes removed. No original board geometry is copied.
